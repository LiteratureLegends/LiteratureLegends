## Initial Brainstorming ideas - 6 minimum
_The group met to discuss possible app ideas._
- Fantasy Football Mock Draft
- Resume Builder
- Job Finder
- Incremental Idle Game
- Sandwich Slicer Game (Fruit Ninja Clone)
- Literature and Research Assistant

## Evaluation of top 3 ideas
> ### Fantasy Football Mock Draft
> The purpose of this application is to simulate a football fantasy draft.
> - The user can set a draft for a certain week and simulate how their team would've done based on player conditions.
> - The user can match up against a computer.
> - The user can save/store preferences of potential draft selections for the upcoming year.

> ### Sandwich Slicer Game
> The purpose of this application is to play a fun game where you swipe across common sandwich toppings.
> - The user loads into a game where assorted pieces of ham, cheese, pickles, tomatoes fly onto the screen and they swipe them.
> - The user receives a score at the end of a set timer.
> - The user can track their hiscores across a leaderboard of all playing users.

> ### Literature and Research Assistant
> The purpose of this application is to help a student or researcher find studies, essays, and more across any available scholar sites.
> - The user can conversate with artificial intelligence to describe their current research goal, and it returns with links to scholar docuemnts.
> - The user can create a project to outline multiple research questions for one particular study.
> - The user can share research projects with multiple collaborators across the app user base.

## Final app idea chosen
### Literature and Research Assistant
We chose this application because as students we understand the struggles with compiling your work. To ensure that you have all the information you need to make an informed decision on a hypothesis. Students commonly need help with multiple problems when writing a paper or study.
- Has there are already been research on this topic and what have they discovered?
- How can I organize my work to make sure everything can be referenced back to my citations?
- If I'm in a group, how can I confirm that we are going off the same material research?
